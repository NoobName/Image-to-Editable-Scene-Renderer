# Image-to-Editable-Scene Renderer

一个面向 Windows 的**单图场景重建、实时渲染与交互重光照工具**。项目结合预训练视觉模型、几何重建与自研 **DirectX 12 Renderer**，让用户从一张照片、数字绘画或概念设计图出发，得到近似可编辑的三维场景，并在固定视角下调整原图的照明。

你可以从一张图像出发，分析深度、法线、物体区域与材质，在三维场景中编辑物体和光源，也可以保留原图的构图与细节，在固定视角下调整光照并导出结果。项目同时可作为独立的 **PBR Viewer / Look Development Tool**，直接查看和编辑 glTF 模型。

## 工作流程

```text
输入图像
   ↓
几何、区域、材质与光照分析
   ↓
ScenePackage：原图 + 分析数据 + 近似三维场景
   ├─ 三维场景：自由浏览 → 物体、材质、灯光与环境编辑
   └─ 图像重光照：对比原图 → 调整目标照明 → 保存配方 / 导出原尺寸结果
```

已有 glTF 模型可以直接进入三维场景；已有 ScenePackage 可以跳过模型推理，直接加载和编辑。图像分析属于离线准备，灯光与材质调整由 Renderer 实时响应。

## 两种工作模式

| 模式 | 工作对象 | 主要用途 |
| --- | --- | --- |
| **三维场景 · 3D Scene** | 重建网格或导入的 glTF 模型 | 自由浏览、选择物体、修改变换与材质、调整灯光和 HDR 环境 |
| **图像重光照 · Image Relighting** | 固定来源相机下的原图与分析数据 | 保留原图细节，交互修改目标照明、保护指定区域、对比并导出图像 |

两种模式分别维护会话中的编辑状态。移动三维相机、隐藏物体或修改三维灯光，不会改变图像模式的来源相机和原图。原图始终作为固定的外观依据，重光照结果与原图分开保存；图像编辑可保存为配方，三维编辑目前仅在当前会话中生效。

## 主要功能

### 单图分析与场景重建

- 输入 JPEG / PNG，通过可替换的 Python Backend / Adapter 接入预训练模型，无需训练自己的网络。
- 集成 **MoGe-2** 几何预测、**SAM 2** 区域分割，以及 **Marigold** 材质与本征分解，获取深度、点位置、几何法线、相机参数及反照率、粗糙度、金属度等信息。
- 从深度和点图构建 **2.5D 网格**，过滤无效像素和深度断层，支持移动相机时的视差观察。
- 将分割区域组织成独立对象，提供对象选择、显隐、位置、旋转、缩放和材质编辑。
- 分别保存原尺寸规范化图像与较低分辨率的分析数据，保留来源、坐标映射与模型版本信息。
- 在界面中启动后台重建、查看进度或取消任务；成功后自动加载场景，失败时保留当前工作内容。

### 实时 PBR 渲染与场景编辑

- 支持 **glTF 2.0 / GLB** 导入、节点变换及常用 PBR 纹理；缺少切线时可计算切线。
- 使用 **Cook–Torrance BRDF**，包含 GGX、Smith 和 Schlick Fresnel，支持基础色、金属度、粗糙度、法线贴图、AO 与自发光。
- 支持方向光和点光源、方向光 Shadow Mapping、PCF 与阴影偏移调节。
- 支持 HDR 环境贴图、天空盒、漫反射辐照度、镜面预过滤与 BRDF LUT；环境实际参与照明和反射。
- 提供曝光、色调映射（None / Reinhard / ACES）、Bloom、色温、色调、饱和度、对比度与暗角。
- 提供中文属性面板、场景层级、自由相机和视口灯光控件。

### 保留原图细节的交互重光照

- 根据固定几何和来源光照，分别计算原始与目标明暗响应，通过有界变化合成重光照图像。
- 调整目标方向光、颜色、强度与环境补光；来源光照校准与目标编辑分开管理。
- **手动添加点光源**：点击画面放置、拖动彩色圆点移动，在属性面板调整深度、颜色、强度与范围；虚线显示球形影响范围。
- 结合几何有效性、置信度和区域保护，限制不可靠区域的修改；提供保守的方向光高光与成对投影阴影处理。
- 提供独立二维缩放、平移、适应窗口、并排对比、擦除对比及低置信度叠加显示。
- 可选的深度引导额外雾效，支持密度与空气光颜色调节，默认关闭。

三维与图像模式中的点光源独立编辑。三维场景最多支持 **8 个光源**（含方向光），图像模式最多支持 **4 个点光源**。图像点光源需要有效的几何、相机和来源光照数据。

### 参考图、配方与导出

- 从参考图提出可检查的目标光照建议，显示参数、置信度与拟合残差，再由用户决定是否应用。
- 区分同场景参考与不同内容参考；不同内容主要迁移照明统计，不进行逐像素内容匹配。
- 支持有界、可取消的低维照明参数优化，并通过实际 DX12 明暗输出复核候选。
- 使用 **Relighting Recipe** 保存来源身份、校准基准、目标光照、图像点光源、响应参数、区域保护与显示曝光，支持重新打开和命令行复现。
- 导出原尺寸 **sRGB PNG**、线性浮点 **DDS** 及调试数据，不包含 UI、辅助线或视口留白。
- 提供默认关闭的离线神经细化选项，保留物理渲染结果与模型候选，支持原图 / 物理结果 / 候选结果对比。

### 可检查的中间结果

提供原图、深度、几何法线、点位置、有效区、区域标签、估计材质、原始 / 目标明暗、照明比率、置信度、残差、高光和阴影等调试视图，便于判断变化来自哪里。数值调试视图绕过艺术后处理；缺少数据时明确显示不可用。

## 技术栈

| 模块 | 技术 |
| --- | --- |
| 实时渲染 | C++20、DirectX 12、HLSL、DXC |
| 窗口与界面 | Win32、Dear ImGui、DirectXMath |
| 资产与数据 | glTF 2.0 / GLB、WIC、JSON、受限数值 DDS、EXR / NPZ |
| 图像分析 | 独立 Python 环境、PyTorch、预训练模型 Adapter |
| 工程构建 | CMake、Ninja、MSVC |

C++ Renderer 与 Python 重建管线通过 **ScenePackage（JSON + 磁盘文件）** 交换数据。Renderer 不链接 Python runtime，也不绑定具体神经网络；加载已有场景包、查看模型和实时渲染无需运行模型推理。

## 快速开始

### 编译并打开三维示例

需要 Windows 10/11 x64、Visual Studio 2022 或更新版本的 C++ 桌面工具链、CMake 3.25+、Ninja，以及包含 DXC 的 Windows SDK。硬件渲染需要支持 DirectX 12 / Shader Model 6.0 的 GPU；Debug 配置还需要 Windows Graphics Tools 提供的 D3D12 Debug Layer。

在项目根目录打开 PowerShell：

```powershell
# 自动寻找 Visual Studio，构建 Debug / Release 并运行 CTest
.\tools\Build.ps1

# 打开内置场景，不需要 Python 或模型权重
.\build\Debug\ImageSceneRenderer.exe --ui

# 查看仓库自带的 PBR 测试模型
.\build\Debug\ImageSceneRenderer.exe --model "assets/models/MaterialLab/MaterialLab.glb" --ui
```

也可以在 **x64 Developer PowerShell** 中仅构建交互程序：

```powershell
cmake --preset windows
cmake --build --preset debug --target ImageSceneRenderer
```

着色器和运行资产会复制到程序旁。模型路径使用双引号；需要软件渲染验证时可追加 `--warp`。

### 从自己的图像开始

1. 按 [几何模型配置](tools/reconstruction/MoGe.md)、[分割配置](tools/reconstruction/Segmentation.md)和[材质配置](tools/reconstruction/Material.md)准备独立 Python 环境与相应权重。
2. 打开程序，在 **文件 → 重建设置** 中选择解释器、后端及分析尺寸。
3. 选择 **文件 → 从图像重建…**，等待后台处理完成并自动加载。
4. 在主视口切换 **三维场景 / 图像重光照**，编辑物体或目标光照；在 **配方 / 导出** 中保存图像编辑并导出结果。

真实模型推理需要单独配置依赖和权重。Dummy 后端可用于验证文件交换流程，但不提供真实场景理解。模型配置和缓存就绪后，可使用已有离线流程。

已有场景包或配方可直接打开。下面的路径表示你自己的输出，并非仓库预置文件：

```powershell
.\build\Debug\ImageSceneRenderer.exe --package "generated/my-scene" --work-mode image --ui
.\build\Debug\ImageSceneRenderer.exe --recipe "generated/my-recipe.json" --ui
```

基本操作：三维模式使用右键转向、WASDQE 移动、滚轮前后移动；图像模式使用滚轮缩放、中键平移。点光源通过“添加点光源”进入放置状态，左键拖动位置圆点，Esc 取消放置。

## 当前边界

- **单图重建是近似 2.5D，而非完整三维扫描。** 未观察到的背面、遮挡区域和隐藏几何不会自动补全，大幅移动相机可能暴露空洞。
- **材质与照明估计存在歧义。** 镜面、玻璃、深阴影、饱和高光及绘画内容可能产生不可靠结果；相对照明参数不等于真实光度测量。
- **两条渲染路径的能力不同。** 三维模式提供 PBR 直接光与环境反射；图像点光源当前仅增加漫反射，不增加点光源镜面高光。两种模式均未实现点光源投射阴影。
- **图像重光照受保护与变化范围约束。** 不承诺任意幅度的昼夜转换、准确去雾或重建不可见反射。额外雾效只增加气氛，不反推并移除原雾。
- **配方保存图像编辑，不是通用三维工程存档。** 三维物体、材质和灯光编辑目前仅保留在当前会话，尚无完整场景保存或 Undo 系统。
- **原尺寸导出有显式资源上限。** 当前单边最多 8192 像素、总量最多 8 MiPixels；超限会明确拒绝，不静默降到分析分辨率。浮点结果是线性、面向显示的图像数据，不代表恢复出的真实 HDR 辐射亮度。
- **部分扩展有适用范围。** 当前方向光专用的逆优化和离线神经细化不接受包含图像点光源的配方；神经候选可能改变内容，默认关闭，不覆盖原图。
