# Conservative directional specular handling (stage25)

The renderer derives `SpecularEvidence` from immutable SourceObservation data; no new model, cache sidecar or altered source RGB is needed. Analysis normal/point/MR/albedo, intrinsic residual/error/uncertainty, validity and the lighting fit mask remain separate evidence. Missing data or fewer than 16 scale samples disables this feature.

Only dielectric-like evidence is supported: source roughness [.2,.8], metallic <= .3, material quality > .2, valid geometry/intrinsics and lighting fit support. A bounded global scale [.05,4] is the median positive residual luminance / calculated old GGX luminance. Per-pixel residual disagreement, intrinsic reconstruction error and uncertainty reduce confidence; strong unexplained residual, negative residual, emitters excluded by the fit mask and reflection suspects are protected. These are heuristics, not confirmed specular segmentation.

View is `normalize(-pointMap)` in the fixed LH source camera. Directional GGX shares `BRDFMath.hlsli` with PBR, using Smith and Schlick, alpha=roughness². Incident coefficients are pi times the relative Lambert direct RGB, followed by the global scale. There is no environment reflection, refraction, point-light highlight or cast-shadow reconstruction. Target roughness response changes only the target evaluation, not source material.

Supported original component C is bounded by positive residual, old GGX and .6*OriginalLinear. Its diffuse anchor is OriginalLinear-C, which recomposes with C exactly in real arithmetic. CPU and per-source-pixel clipping are reported. The final expression is `Original*ratio + C*(1-ratio) + delta`; delta is the confidence-weighted, bounded difference between paired new/old specular, lower-bounded by -C. No complete residual removal or whole-image PBR replacement occurs. Identity returns Original, zero strength/protection returns the preceding result, and disabling restores stage24 byte-for-byte. Default specular strength .25; target roughness scale1; positive delta cap .15*Original + .02*editAmount.

UI: **Conservative specular handling**, **Specular edit strength**, **Target roughness response**, **Reset specular response**. CLI `--no-specular` disables the feature, including subsequent source publications. Existing `--protection-mask` white pixels protect both diffuse and specular edits. Applying source calibration invalidates the fixed separation until an offline fit is exported/reloaded.

Debug keys append: `specular-candidate`, `specular-confidence`, `diffuse-anchor`, `old-specular`, `new-specular`, `specular-delta`, `specular-clip`, `specular-difference`, `specular-protected`. Purple indicates missing/stale support. Four additional analysis-resolution RGBA32F resources are read back with explicit resource states; no PBR texture slot is repurposed.

Validation: `tools/Validate-Specular.ps1`, `tools/reconstruction/specular_examples.py`, `verify_specular.py`, `tests/test_specular.py`. Known plane/sphere GGX peaks move, larger roughness broadens/lowers them, source/target identity is <=1 LSB and disabling matches the stored stage24 result. Raw GGX float32 peaks use absolute+relative numerical tolerance; the bounded final image retains a strict absolute test.
