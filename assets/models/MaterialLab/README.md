# MaterialLab fixture

Original procedural test assets authored for ImageSceneRenderer. The geometry and four PNGs are generated by `tools/GenerateAssets.cpp`; no third-party model or texture is used. They may be used and modified with this project.

- Cube, sphere, plane; a shared mirrored sphere instance under a rotated parent.
- Interleaved POSITION/NORMAL/UV, 16-bit indices, deliberately absent TANGENT.
- Shared base color and packed ORM textures; normal and emissive maps.
- `.gltf` exercises a percent-encoded image URI; `.glb` embeds identical geometry and images.
- Lower half of ORM is metallic, upper half dielectric; roughness varies along U and AO along V. Dark metal without environment lighting is expected.

Regenerate from the project root with `build/Debug/GenerateAssets.exe assets/models/MaterialLab`.
