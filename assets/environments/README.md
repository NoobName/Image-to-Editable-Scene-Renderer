# HDR environment fixtures

SoftStudio.hdr and SunsetCourtyard.hdr are original, deterministic synthetic radiance panoramas generated by tools/GenerateEnvironments.cpp. They are not photographs. No external HDRI license is required for these authored test assets; use and modify them with this project.

Both use Radiance RGBE, modern per-channel scanline RLE, 512x256 equirectangular layout. Values exceed 1. SoftStudio contains broad blue-white rectangular lights and a red side panel. SunsetCourtyard has a warm sun, colored horizon and dark green occluder region.

Rebuild with: build/Debug/GenerateEnvironments.exe assets/environments

The executable also accepts your own Y-major Radiance RGBE .hdr panoramas via --env or the UI. EXR and legacy RGBE repeat packets are currently unsupported.
